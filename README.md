# 🚀 Featured Project

## 🏙️ [Real Estate Intelligence Platform](https://github.com/kush10521/Real-Estate_Intelligence_Platform)

End-to-end ML platform for the **Gurgaon real estate market** — built from the ground up, including web scraping, feature engineering, and a deployed interactive app.

- 🕷️ Scraped and cleaned property data using **Selenium & BeautifulSoup**; engineered features across **8 selection techniques**
- 🤖 Benchmarked **11 ML algorithms × 3 encoding strategies** → selected Random Forest achieving **R² ≈ 0.90**
- 🎯 Built a **content-based recommendation engine** using weighted cosine similarity on amenities, price, and location
- 📊 Deployed a **Streamlit** app with price prediction, an analytics dashboard, and geo-visualizations — live on **AWS EC2**

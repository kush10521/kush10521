# Contributing

Thanks for your interest in improving this GitHub profile repository.

## Ways to contribute

- Improve the profile content and messaging in `README.md`
- Add useful project highlights or reusable templates
- Suggest better badges, sections, or layout improvements
- Share feedback on readability and structure

## Pull request guidelines

1. Keep the changes focused and relevant.
2. Preserve the profile's professional, technical tone.
3. Verify formatting before submitting.
4. Keep sections concise and visually clean.

## Local review

Open the repository in a browser or Markdown preview tool and check that the content renders clearly.

## Contact

If you want to suggest a major change, please open an issue before submitting a large pull request.
